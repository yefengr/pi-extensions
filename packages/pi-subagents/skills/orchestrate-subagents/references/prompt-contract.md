# Pi 子代理任务契约模板

按任务删除不适用项，但不得省略角色、任务特有权限、所有权、决策边界、验证和停止条件。实现与修复角色还不得删除“推荐实施思路”；其中任一必填项缺失时必须返回 blocked，不得自行补造。自定义 profile 中已固定的通用只读/写入边界、禁止副作用和输出骨架只引用 profile，不在每次 prompt 中逐段复制；有效模型、工具和上下文仍由主 Agent 在派发证据中核对。使用探索或诊断角色时，任务契约必须明确调查问题、搜索范围、关键词、候选数和停止条件；“无匹配”只对该范围成立，不得扩展为全局不存在。使用写作角色时必须填写人类文档写作契约。正文只保留编排原则，本模板负责具体字段和操作约束。

```md
在 `<绝对工作目录>` 中执行以下任务。

## 角色与目标
- 角色：`探索|诊断|实现|写作|审查|修复`
- 角色与 profile：`<运行时实际发现且已启用的 profile 类型>`；不预设候选名单或固定数量。
- 选择依据：<所需能力>；记录候选启用与来源证据、模型可用性、能力与工具/上下文匹配；未选候选仅在必要处简述差异。
- 负责：<可独立验收的结果>
- 非目标：<本次任务特有且不得承担或顺手处理的范围>

## 交接与证据
- 交接方式：`内联 | .pi/tmp/<task>-evidence.md`
- 契约/证据版本：`<版本、时间或冻结产物标识>`

### 关键交接项
- `F1 [frozen/stable]`：<结论>
  - 证据：<文件与符号、限定命令或运行结果>
  - 适用范围：<消费者与边界>
  - 复核角色：<无需复核或指定角色>
  - 失效条件：<何时重验>
- `R1 [review/snapshot]`：<仅由 reviewer 定向核验的高风险断言>
- `U1 [unresolved]`：<必须返回父 Agent 决定>
- `D1 [disproved]`：<不得继续采用的假设及最小证据>

- 无需重复调查：<仍有效的扫描、构建或测试证据>
- 易变事实：<运行状态、当前文件或外部状态；使用前重验>

## 输入、依赖与兼容边界
- 输入和冻结产物：<文件、diff、接口、数据或上游结论>
- 直接消费者：<代码、流程、用户或下游节点>
- 依赖关系：<上游、下游、串并行约束>
- 直接耦合文件分类：<生产源码、直接测试、fixture/snapshot/测试辅助、manifest/依赖/结构断言，以及行为变化必须同步的文档>
- 共享集成文件及唯一 owner：<文件与唯一 integration owner；无则写“无”>
- 串行依赖：<必须先后交接的节点与依赖字段；无则写“无”>
- 兼容边界：<必须保持的 API、数据、行为或“无适用项”>

### 推荐实施思路（仅实现与修复角色，必填）
- 方案方向：<优先采用的实现方向及理由>
- 执行顺序：<先后步骤、依赖与检查点>
- 必须复用：<项目模式、现有组件、冻结事实或接口>
- 必须保持：<行为、兼容、安全、性能或无关改动边界>
- 不建议路线：<已排除或不应采用的方案及原因>
- 偏离回传：<何种证据触发停止；返回原路线、最小冲突证据、影响和最小替代方案，等待父 Agent 重新冻结>

缺少上述任一项时，worker 必须在读取任务契约后返回 blocked，不得先调查或编辑后补报。worker 可以自行决定不改变共享契约的局部命名、函数拆分和等价实现细节；证据要求改变推荐方向时必须先回传。

实现与修复任务的契约还须要求 worker 在返回 blocked 或 failed 时标注阻塞分类 `contract | evidence | environment | scope | capability`；父 Agent 据分类重冻结、补证、处理环境或更换能力，不因 blocked/failed 本身或失败次数自动升级模型。

### 人类文档写作契约（仅写作角色）
- 交付模式：`返回正文 | 写入文件`；前者写入范围为空、无需目标文件且返回完整正文，后者交接创建或更新授权、精确路径和增量范围。
- 写作技能入口与必要参考：<本次实际使用的 SKILL.md 及参考文件绝对路径，纳入允许读取范围；不猜测安装路径>
- 目标读者、阅读场景和文档目的：<...>
- 冻结事实、术语、结论及证据位置：<...>
- 必须包含、不得包含和未确定内容：<...>
- 允许调整的结构与期望文风：<必须保留的章节、可自行组织提纲或调整段落的范围；不要求父 Agent 预写完整初稿>
- 必须原样保留的代码块、命令、路径、配置、表格或引用：<...>
- 子任务直接执行写作与自查，不再进行宿主的角色选择、委派或事实调查；材料或授权不足时返回父 Agent。

## 所有权、权限与副作用
- owner：`<代理 ID/类型>`；共享契约 owner 为父 Agent。
- 允许读取：`<文件、目录或 pathspec>`
- 允许修改：`<精确文件清单>`，或“只读”
- 用户授权：<本任务继承的授权>
- 允许的副作用：<无或逐项列出>
- 禁止：<范围外写入、联网、数据库、提交、push、部署等适用项>
- 未明确允许的外部副作用一律禁止；保留其他参与者改动，不得回滚或覆盖。
- 派发门禁（写入型节点）：所有直接耦合文件都必须已经盘点且存在唯一写入 owner；任一项未归属时不得派发，返回 blocked。只读节点不适用。

## 运行与决策边界
- Agent profile：`type=<运行时实际发现且已启用的类型>`，`enabled=true`，`source=<发现来源>`，定义路径或版本 `<path/hash>`。
- 职责与有效能力证据：`职责=<与本次角色匹配的职责边界>`，`model=<有效模型或 unknown>`，`thinking=<有效等级或 unknown>`，工具 `<列表>`，上下文 `fresh | inherited`，`max_turns=<值>`；其余资源上限（如最长运行时长、wrap-up 行为）必须记录本次有效限制或引用其运行时证据，profile 声明只作配置基线，不能替代本次调用的最终有效预算。
- 可自行决定：<不影响共享契约的局部事项>
- 必须返回：<接口、协议、兼容、安全、迁移、范围扩大等共享决策>

## 实施、预算与停止条件
- 限定搜索：<目录、关键词、候选数和停止条件>
- 软预算检查点：<调用次数；参考下表>
- 验证：`<目标命令、检查或证据>`
- 不重复运行：<父 Agent 已持有且仍有效的验证>

达到停止条件、预算检查点仍无法收敛，或发现范围/权限/契约冲突时停止。返回已用证据、缺失信息、影响、最小扩围或替代方案和剩余风险；不得自行扩围、改变共享契约、执行破坏性操作或提交。

## 输出格式
自定义 profile 默认沿用其输出格式；只有下游需要额外字段时在此追加，不重复整段 profile。未使用专用 profile 时采用以下兜底：

status: completed | blocked | failed

阻塞分类：`contract | evidence | environment | scope | capability | none`

### 已完成
- ...

### 新增或确认的事实
- `F<n> [状态/生命周期]`：<结论>
  - 证据：<文件、符号、命令或运行结果>
  - 适用范围与失效条件：<...>

### 产物与修改文件
- ...

### 验证
- `<命令>` → <退出状态和结果>

### 与冻结契约的冲突
- 无 | <原事实、最小冲突证据和影响>

### decisions_needed
- ...

### remaining_risks
- ...

### 建议传递给下一个角色
- ...
```

## 软预算参考

预算是触发父 Agent 决策的检查点，不是降低质量的硬上限。根据任务风险和范围调整；诊断任务不设固定区间，由父 Agent 按复现步骤、假设数量和停止条件确定检查点：

| 角色 | 建议检查点 |
|---|---:|
| 探索任务定向探索 | 12–20 次只读/搜索调用 |
| 契约调查 | 25–35 次只读/搜索调用 |
| 写作任务文档落笔 | 6–12 次读取与编辑调用 |
| 实现任务首次编辑前 | 最多 10 次只读调用 |
| 审查任务冻结 diff 审查 | 总计 15–25 次调用；两阶段复用同一读取证据 |
| finding 修复 | 仅读 finding 涉及区间、目标文件和必要配置 |
| 独立关闭核对 | 5–10 次调用 |

## 精确编辑协议

写入型子代理依次执行：

1. 编辑前即时读取目标稳定区间，不复用旧摘要或旧 diff 文本。
2. 使用最小唯一匹配；同文件不相邻修改合并为一次编辑调用，相邻修改合并为一个替换块。
3. 读取后紧邻编辑；期间可能发生其他写入时重新读取。
4. 首次匹配失败后重新读取并基于现状重建替换；第二次仍失败则停止报告，不猜测重试。
5. 编辑后定向检查目标和 diff，并运行适用验证。

## 只读审查补充

审查契约还必须写明：

- 冻结 diff、commit、文档版本或 pathspec；
- 已有验证及其快照版本；
- 负责和排除的风险维度；
- finding 级别与证据要求；
- 实际实现者和审查者模型族、审查者是否参与对应实现与覆盖证据。模型族按实际模型系谱判定，不按 provider、profile 名或是否新建会话推断；覆盖不足、实际模型族不明或同族时审查者必须返回 blocked，不以异族或新会话替代能力与覆盖证明。

除安全或破坏性阻断外，应完整覆盖风险矩阵；覆盖完成即返回，不继续泛化搜索。无 finding 时仍说明测试缺口和剩余风险。
